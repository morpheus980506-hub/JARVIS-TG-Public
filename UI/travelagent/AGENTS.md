# AGENTS

TravelAgent 是本地桌面旅游 Agent，提供旅行对话、地图、行程、预算和本地文件工具，仅使用 DeepSeek 模型。

## 技术栈与开发约定

- 使用 pnpm、TypeScript、Electron Forge、Electron、React、LangChain、LangGraph、Tailwind CSS 和 shadcn。
- 优先复用现有能力；按职责拆分文件，避免超长文件。重构时清理旧代码和无用文件。
- 渲染层按布局、聊天、侧栏、输入框、设置和工作台拆分，应用状态由 hook 管理。主进程按启动、IPC、地图代理、模型创建和命令审查拆分；流式事件转换保持为可独立测试的纯函数。
- 业务样式使用 Tailwind 与 shadcn 组件变体。公共 CSS 仅保留主题、基础规则和公共动画；Markdown 与 JSON 样式放在对应展示组件。
- 长期架构、行为或安全约束变更时更新本文。不要记录短期文案、尺寸和修改历史。

## 模型、配置与密钥

- 对话、命令审查和摘要统一通过 LangChain ChatAnthropic 调用 DeepSeek 官方 Anthropic Messages 兼容接口。会话标题随首次对话请求生成；无标题时使用本地兜底，手动标题优先。不得增加其他模型服务、协议、自定义请求头或独立审查模型入口。迁移旧配置时保留模型、思考强度和有效密钥覆盖。
- 模型目录直接读取官方 `/models`，不拼接到 `/anthropic` 下；名称、原始 ID、上下文长度、输入模态和思考强度以接口返回为准，不硬编码强度列表。未选择强度时默认 high；模型不支持时回退到目录默认值或 none。通过 `thinking.type` 与 `output_config.effort` 传递选择；none 关闭思考，其余使用 adaptive。切换模型时保留仍兼容的选择。
- 公开仓库的 `src/demo-config.ts` 仅保留演示账号、默认模型和空服务密钥，禁止提交真实凭据。本机密钥通过设置填写并加密持久化；不得把本机配置、数据库或私人仓库历史合入公开仓库。预设更新替换旧预设覆盖，自定义覆盖保留，重新登录恢复账号预设。
- 对话、命令审查、网页工具与听写共用当前生效的 DeepSeek 密钥。启动时退役旧的独立网页工具密钥，并清理历史中可识别的密钥。
- 设置应区分账号接管、代码预设和自定义来源，保留 ARIA 关联。账号接管时禁止编辑、删除和保存覆盖；不向界面暴露实际密钥，仍允许测试连接。
- 会话、工具记录、模型历史和日志统一脱敏已配置密钥；流式脱敏须覆盖跨分片密钥。

## Agent、会话与上下文

- LangGraph 管理模型、工具节点和条件边。工具顺序执行并统一经过追踪、参数校验和命令审查。取消后不得启动下一节点；当前节点结束前不得释放会话执行锁。不要依赖框架默认的 25 步限制。
- 用户意图或关键条件不确定且会影响结果时，使用 `ask_user` 合并澄清问题并结束当前轮次，跳过同批次其他调用。问题随对话保存；待答问题在聊天底部逐题呈现，支持点选、填写、跳过，也可关闭面板后普通回复。问卷答案作为下一条模型输入继续；界面合并前后处理过程，不展示拼接输入，累计用时不包括等待回答的间隔。提交面板时保留草稿和附件。
- 系统提示词与摘要提示词分开维护，并明确任务条件、证据时效和不可信数据边界。历史摘要不得覆盖当前用户纠正或授权的工具操作。
- 按模型目录预算上下文；未知时采用保守预算，并预留系统提示、工具定义、输出和安全余量。大型工具结果仅截断模型视图，完整过程记录保留。压缩旧历史时以完整用户轮次为单位，不拆分工具调用与结果。
- 摘要不得包含内部推理或大型工具载荷，也不得写回原始历史。摘要失败时回退到有界摘录；编辑重发不得复用过期摘要。当前轮次仍超预算时明确报错，不静默丢弃用户要求。
- 顶栏显示最近一次模型请求的 Token 总量和上下文占比；详情展示缓存命中率、未缓存输入、缓存输入和输出，以及系统提示、工具定义和对话消息的估算分项。总量采用接口用量，占比按模型目录窗口上限计算；分项按请求大小分摊并标明估算。优先采用 DeepSeek 流式结束事件用量，缺失数值显示为零；缺少用量或上限时不估算占比，旧记录缺少分项时显示未知。精确输入和输出仍须通过可访问说明保留。
- 消息适配保留思考块、签名、工具调用 ID 和内容顺序，并兼容旧历史。中止调用补齐未知结果，禁止自动重复命令；流式结束时检查截断和不完整响应。
- 处理过程在执行和等待澄清时展开，按序显示行动说明、工具调用与待答状态；标题只显示真实耗时，结束后自动折叠且可手动展开。思考阶段依据流式事件计时，以默认折叠的 Reasoning 行显示状态与耗时，展开后显示脱敏原文。签名和供应商隐藏的思考块仅用于协议回传。行动说明、最终答复和审批分开展示；工具详情区分参数、说明与结果，不推算缺失数据。
- 最新模型文本流式显示为正文；确定随附工具调用时，转为处理过程中的行动说明。运行期间禁止折叠整个处理过程并隐藏折叠箭头；自然结束或手动停止后折叠。手动停止时正文替换为弱化的“已手动停止”。
- 用户消息可编辑重发；重发须清除后续对话和过期行程。生成期间禁用编辑与模型切换。消息支持复制原文及结果反馈。

## 外部工具与旅行数据

- MCP 配置保存在本机；外部服务默认使用 stdio，也支持 Streamable HTTP。连接和工具适配优先复用 LangChain MCP 适配器。保留原始 JSON Schema；预算、模型绑定须兼容 JSON Schema 与 Zod，参数校验复用 LangChain，工具名称按服务隔离。服务启动失败应记录过程提示，不阻断普通对话。
- 内置 12306 不依赖外部 Node 或 npx，使用官方车站与余票接口，覆盖北京时间、城市和车站、直达、中转及经停。结果附来源和查询时间；票价缺失保持未知，不虚构票价或余票，也不把接口失败当作无票。
- 12306 站点范围区分 `auto`、`exact` 和 `city`；先按实际站点过滤，再排序和限量。乘车日与始发日分开，中转须校验历时、等待、日期和跨站信息。最多读取三页并去重；未读完、游标重复或记录校验失败均须标记搜索不完整。
- 滴滴使用官方 Streamable HTTP，密钥仅由主进程发送，设置只返回状态和掩码。发现与调用都使用固定查询白名单；禁止创建或取消订单、生成打车链接及未知操作，不得被模型提示或工具注解放开。结果移除打车链接和下单标识，预估价格明确标为估算。
- RollingGo 酒店使用官方 Streamable HTTP 和 LangChain MCP 适配器，密钥由主进程与账号预设统一管理。发现和调用均限定固定查询白名单；禁止创建订单、支付、取消及未知操作。维护或连接失败不得解释为无库存。
- 飞猪与美团酒旅酒店查询由主进程通过固定的本机 JARVIS-TG 只读接口调用，复用本机服务的供应商配置，不向渲染层传递供应商密钥。无日期时只提供酒店名单与详情链接；按平台区分错误和无可用结果。
- VariFlight Aviation 使用官方 Streamable HTTP 与 `X-API-Key`，由主进程通过 LangChain MCP 适配器连接。密钥纳入账号预设、加密覆盖和统一脱敏。发现和调用均限于固定航空查询白名单，不开放下单、支付、订单变更或未知工具。结果附来源和应用查询时间；失败不得解释为无航班或无票。

## 附件、文件与工作区

- 应用数据库、附件、文件备份、诊断日志和默认文件工作区放在用户主目录的 `.travelagent` 下。Electron 继续使用自身的渲染器缓存和配置目录。
- 新建对话默认使用内置工作区，也可选择本机登记的目录。工作区绑定会话；会话顶栏的文件夹按钮、工具相对路径和命令默认目录均沿用该会话工作区。内置工作区不可移除；移除自定义工作区只取消登记，不删除原目录或已有会话路径。
- 输入框支持添加文件、粘贴图片及原生编辑右键菜单，并支持键盘操作。每条消息最多 10 个附件，每个不超过 20 MB。允许仅发送附件；读取期间禁用发送，失败时恢复草稿。
- 主进程校验附件并以随机 ID 保存，渲染层不能指定读取路径。图片校验真实文件签名并限制尺寸；模型输入与缩略图分别缩放。文本提供有界正文，二进制明确标注尚未解析；所有附件均视为不可信数据。
- 图片使用真实 Messages 图片块；模型明确不支持图片时提示切换。上下文预算包含附件，文本发送前脱敏。
- 会话保存附件元数据和缩略图，模型历史保存引用，避免重复持久化完整图片。重新打开会话与编辑重发须保留附件。草稿和已发送图片支持点击或键盘查看原图；预览按 ID 按需读取，并提供失败重试、Escape 关闭和焦点恢复。

## 定位、规划与地图

- 规划需要当前出发地且用户未指定时，Agent 主动调用 `get_current_location`，不提供手动定位入口。每轮最多请求一次并保留工具追踪；用户明确拒绝时不调用，权限拒绝或取消后不换渠道、不重试，也不通过命令绕过定位。
- Windows 优先使用系统 WinRT Geolocator，通过固定、无参数的 Windows PowerShell 脚本访问；窗口隐藏、设置超时并支持取消，不接受模型脚本或命令输入。系统服务不可用时才尝试浏览器 Geolocation。仅主进程存在有效待处理请求时允许主页面定位；地图 iframe 不获定位权限，迟到或错误请求 ID 的响应不得采纳。
- 主进程校验坐标、精度、采集时间和来源。高德官方接口将 WGS84 转为 GCJ-02 后解析地址；转换失败时保留原坐标并明确地址未知，不混用坐标系，不以自建 IP 推测替代定位。位置只随工具记录进入当前会话，不全局保存或后台跟踪；取消或窗口重载须终止请求并撤销浏览器权限。
- 规划优先采用用户明确提供的出发地；主动定位仅作为当前出发地候选。旧历史、过期位置或低精度接驳点须确认。定位失败后询问出发地，再补齐日期、人数和预算；核实跨城交通、住宿与市内路线后按需发布行程。
- 地图填满工作台可用空间，按天筛选并提供地点、时间和说明列表。标记使用明确锚点和稳定编号；同坐标记录合并展示。只接受有效 GCJ-02 行程坐标，不得直接绘制 WGS84。没有真实道路轨迹时不画地点连线，不把顺序示意冒充路线。
- 高德地图在不同来源的沙盒 iframe 中加载，保留 SDK 内部 iframe 所需的同源能力；仅地图页允许 SDK 动态脚本，主页面保持严格 CSP。安全密钥由随机能力路径的本机代理注入。加载成功后才提示就绪；失败或超时回退静态预览。

## 界面、可访问性与平台

- 保持简洁一致并复用 shadcn；统一主题变量，确保浅色和深色可读。原生菜单跟随应用外观设置。启动占位样式不得影响正文。
- 侧栏和工作台使用 Resizable，支持拖动、键盘调整和本机宽度记忆；工作台完整视图隐藏并禁用后方侧栏。聊天仅消息区滚动，顶栏和输入框固定；MessageScroller 管理滚动跟随与边缘渐变，且不得阻挡交互。
- 流式输出期间保持滚动条占位和正文容器稳定；处理过程折叠不得重挂正文。结束事件和保存后的会话应一次更新。
- 模型菜单只展示模型与思考强度；预取并静默刷新，失败可重试。设置默认打开“外观”；新建聊天欢迎页隐藏聊天顶栏且不自动聚焦输入框。
- 图标按钮须有明确名称；导航暴露当前项和展开状态，滚动区有名称。输入说明、配置来源和表单错误保留 ARIA 关联。遵循减少动态效果设置，并保留键盘焦点反馈；jsx-a11y 例外须说明原因。
- 输入框聚焦时只高亮边缘，边缘宽度保持一致；组合输入框在外层显示焦点。界面控件、导航和状态文案默认不可选中；正文、工具详情、行程数据和可编辑文本可选中，并能通过原生右键菜单复制。
- 聊天听写由用户启动，通过模态对话框显示录音和转写状态，并提供结束和取消操作。麦克风权限仅在主页面录音时短暂授予。主进程使用 DeepSeek 主密钥提交单声道 PCM WAV 至官方 ASR。原始录音仅在内存保留；转写追加到可编辑草稿，由用户决定是否发送。
- 侧栏与工作台宽度由主进程存入应用数据库。主进程向用户日志目录的 `main.log` 写入有体积限制的脱敏诊断；写入失败不得影响运行。启动应提供占位、开发入口预热和卡住恢复；渲染异常提供重新加载操作。

## 检查与验证

- `pnpm check` 依次运行 oxfmt、Oxlint（含 jsx-a11y）、TypeScript 和单元测试。使用单元测试验证业务逻辑。
- 功能和界面修改默认完整运行应用，并通过电脑控制与截图检查交互和主题；用户明确要求跳过时遵照要求，并说明未验证范围。
- 本地功能检查应验证标题随首个流式回复返回；失败时以非零退出码结束。
