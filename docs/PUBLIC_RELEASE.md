# V0.8.0 公开源码说明

## 范围

本仓库用于比赛评审及本机运行复现，包含桌面客户端、网页版、后端、测试和开发文档。公开代码从当前 V0.8.0 快照建立独立提交历史；原私有仓库保留。

- 不包含真实 API/MCP Key、访问令牌、Cookie 或私人账号凭据。
- 不包含 `.env`、本机数据库、对话、附件、诊断日志、打包产物、依赖或团队原始交付目录。
- `UI/travelagent/src/demo-config.ts` 的所有服务密钥为空。请在本机设置中填写自己的凭据。
- `admin / 123456` 是用于本机账户交互的公开演示值，不承担数据访问控制，不应作为任何实际账户密码使用。
- 测试中的城市、地址、示例路径和模拟凭据用于验证行为，不代表真实查询结果。历史测试报告保留其原版本和日期，不表示本版本全部再次完成同样的实网验证。

## 运行

桌面端请参照 `UI/travelagent/README.md`，使用 Node.js 26.13.0 和 pnpm 12。安装依赖后可直接 `pnpm start`；飞猪、美团等桥接查询还需按根目录 README 安装并运行后端。

网页版和后端请参照根目录 README，先复制空模板 `.env.example` 为本机 `.env`。Python 版本固定为 3.12。不要上传填好密钥的 `.env` 或修改后的预置密钥文件。

## 数据性质与限制

界面预算中的估算和未知不是实时成交价；地图地点标记不是道路导航轨迹。供应商可用性、授权、配额、网络和日期均可能影响查询结果。当前版本不执行真实购票、支付或预订。
