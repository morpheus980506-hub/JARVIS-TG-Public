# Demo Script

## Demo 1：正常规划

输入：“11月20日从兰州出发，去成都玩4天，两个人，预算3500元……”；展示 Planner、并行研究/天气、预算、行程、Verifier 和来源标签。

## Demo 2：酒店与交通授权

展示飞常准真实航班/铁路候选；酒店页展示明确标记的 Mock 候选、预算与取消政策。选择候选后创建 L2 调整请求，在授权中心同意或拒绝。说明当前授权只记录决定，在获得供应商授权前不会声称真实库存或下单。

## Demo 3：突发调整
