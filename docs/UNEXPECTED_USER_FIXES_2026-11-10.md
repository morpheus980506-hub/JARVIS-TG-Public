# V0.6 public.2：非预期表达修复与复测

版本：`0.6.0-public.2`，Python包`0.6.0rc2`，日期2026-11-10。对应[原始专项报告](UNEXPECTED_USER_AUDIT_2026-11-10.md)，保留修复前证据，不覆盖原测试日志。

## 已修复

- 普通摘要询问不再被拆成起终点；摘要使用同一份已确认条件。回复、collected、trip_request与重新打开后的正式请求保持一致。
- “先别改”、不变条件、其他话题和引述中的修改不进入当前旅行条件。出发、回程、景点开放日期和小数天数分开解析。
- 取消会暂停规划并保留聊天；修改已取消行程的预算不会自动恢复，明确恢复后才重新显示生成入口。重新开始会清空有效条件与用于新规划的旧条件文本，保留聊天历史。
- 支持千分位、k、中文金额及否定纠正；人均与总额分别处理。“总预算不变”与“人均预算不变”在人数变化时含义不同。餐厅价格和手机预算不会覆盖旅行预算。
- 家庭组成按整条消息合计，包含婴儿；负数和不支持的小数计数会要求补充，不截断为其他值，也不连带改坏日期。
- 未决定、二选一、范围表达和多城市不再伪装成单个城市或任意确定值；要求明确城市/日期/天数/人民币总预算。连续补充“那就重庆吧”可以恢复有效目的地。
- 支持起终点交换、出发地标签修改，以及英文起点/目的地修改、人数增量、天数减量、取消等表达。更新偏好时移除相反的旧正向偏好。
- 对“先别改，只问哪个更贵”明确说明缺少同日期、同人数、同住宿标准的报价，保留原计划，不输出未经报价支持的票价高低或预算够用结论。

- 后端369项回归通过，新增99项，包括70条原始表达与未出现在报告中的新变体、取消/恢复、重置后新旅行、API保存恢复一致性。
- 前端51项回归、TypeScript检查和Vite生产构建通过；原有大包提示仍在。
- 原70条独立表达从41条偏差变为全部达到预设预期。该结果只代表这些测试，不是自然语言总体准确率。
- 49次真实本机流式对话重放无错误帧；每轮结果的ready和trip_request与GET恢复结果一致。22个QA临时对话全部清理。

- 修复前日志：`backend/logs/unexpected-audit-2026-11-10.json`；复测日志：`backend/logs/unexpected-audit-2026-11-10-fixed.json`。日志已忽略，测试构造输入可通过已提交脚本重放。

## 范围

本轮修改需求理解与条件保持，未扩大成完整的多城市规划、外币换算或婴儿票务规则支持；这些输入会澄清或保留为待核实条件。取消/重置不删除聊天记录或已保存的历史方案。本轮没有下单付款，也没有改动用户历史、密钥或设置。

没有浏览器控制工具；真实点击、地图视觉、定位授权、手机跳转和打印仍未验收。本轮没有重新执行付费完整行程规划，上一版的完整规划核验记录仍作为历史结果。自由咨询的其他回答仍需继续检验资料依据，不因结构化条件修复就视为所有内容均已核实。
