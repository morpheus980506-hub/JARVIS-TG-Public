## 三家密钥配置入口（目前均已配置）

1. [滴滴官方平台](https://mcp.didichuxing.com/)：登录并激活个人 MCP Key。
2. [飞猪 AI 控制台](https://flyai.open.fliggy.com/console)：获取正式 API Key。
3. [美团开发者 Token 页面](https://developer.meituan.com/zh/v2/dev/token)：按官方流程获取 API Token。

三项均填写到本机“设置 → API 接口 → 对应服务 → 配置”。不要发到聊天或提交到 Git。保存沿用 Windows DPAPI 加密存储；空白密钥保留旧值。保存后重新打开查询侧栏以更新配置状态。

## 使用与边界

- 主聊天输入框上方“酒店·预订”打开平台查询，可勾选飞猪、美团并行查询；单家结果独立展示与重试。填写城市、未来日期、人数、预算和需求，避免缺日期时误读报价。
- 行程的住宿页也可直接查询；原有酒店候选仍是模拟预算，默认折叠并明确标注，不自动替换成未经核实的真实库存。
- 价格按平台返回原文展示，缺失价格不补成 0。飞猪仅渲染官方文档中的产品字段；无效响应不显示为已查询成功。
- 调用固定版本官方客户端，仅运行只读搜索命令；密钥通过子进程环境传入，不写命令参数、不返回上游错误详情。没有自动升级或全局安装。
- 美团单次查询上限160秒，飞猪50秒；前端分别展示进度，慢平台不会挡住另一家结果。没有密钥时不使用客户端内置试用凭据冒充个人服务已接通。
- 链接仅展示对应平台允许的 HTTPS 域名，预订在平台内确认。本轮没有接入应用内下单、取消、支付或支付账户绑定。
- 人流热力仍按用户此前选择保留“未接入”；需要真实数据来源。支付方式继续仅保留入口。

## 在新机器安装

安装 Node.js 18 或以上，在 `tools/travel-clients` 中执行 `pnpm install --frozen-lockfile --ignore-scripts`。应用不在运行期间自行下载或执行新版本。
